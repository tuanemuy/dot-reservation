# ページ設計

## 公開ページ（顧客向け）

### トップページ

- **目的**: サービスの入口として、店舗検索への導線を提供する
- **機能**:
    - メインビジュアルの表示
    - キーワード検索バー（店舗名、エリア名、メニュー名）
    - 検索オプション（エリア、カテゴリー）

### 検索結果ページ

- **目的**: 検索条件に合致する店舗を一覧表示し、絞り込みを可能にする
- **機能**:
    - 店舗カードの一覧表示（店舗画像、店舗名、カテゴリー、エリア）
    - 絞り込みフィルター（エリア、カテゴリー）
    - ページネーション
    - 検索結果が0件の場合の案内メッセージ表示

### 店舗詳細ページ

- **目的**: 店舗の詳細情報を提供し、予約への導線を提供する
- **機能**:
    - 店舗基本情報の表示（店舗名、カテゴリー、住所、電話番号、店舗画像）
    - メニュー一覧の表示（メニュー名、所要時間、料金、説明）
    - メニュー詳細の表示（担当可能スタッフ一覧を含む）
    - スタッフ一覧の表示（プロフィール画像、スタッフ名、自己紹介）
    - スタッフ詳細の表示（担当メニュー一覧を含む）
    - アクセス情報の表示
    - 店舗情報の表示
    - 予約フローへの遷移（「予約する」「このメニューで予約する」「このスタッフで予約する」）

### 予約ページ

- **目的**: ステップ形式で予約を完了させる
- **機能**:
    - ステップ1: メニュー選択（一覧から1つ選択、プリセット対応）
    - ステップ2: スタッフ選択（担当可能スタッフ一覧、「指名なし」オプション、プリセット対応）
    - ステップ3: 日時選択（カレンダーで日付選択、空き時間枠の表示・選択）
    - ステップ4: 確認（予約内容の確認、備考入力、未ログイン時のログイン/新規登録誘導）
    - 完了画面（予約確定/リクエスト送信メッセージ、予約サマリー）
    - ステップインジケーター表示
    - 各ステップ間の戻る/進む操作

## 顧客認証ページ

### 顧客新規登録ページ

- **目的**: 顧客アカウントを新規作成する
- **機能**:
    - 登録フォーム（表示名、メールアドレス、パスワード、パスワード確認）
    - バリデーションエラーのインライン表示
    - 確認メール送信完了メッセージの表示
    - ログインページへの誘導リンク

### 顧客メール確認完了ページ

- **目的**: メールアドレスの確認が完了したことを通知する
- **機能**:
    - 確認完了メッセージの表示
    - ログインページへの遷移ボタン

### 顧客ログインページ

- **目的**: 顧客アカウントでログインする
- **機能**:
    - ログインフォーム（メールアドレス、パスワード）
    - 認証エラーメッセージの表示
    - パスワードリセットページへのリンク
    - 新規登録ページへのリンク

### 顧客パスワードリセットページ

- **目的**: パスワードリセット用のメールを送信する
- **機能**:
    - メールアドレス入力フォーム
    - リセットメール送信完了メッセージの表示

### 顧客パスワード再設定ページ

- **目的**: 新しいパスワードを設定する
- **機能**:
    - 新しいパスワードと確認用パスワードの入力フォーム
    - 変更完了メッセージの表示
    - ログインページへの遷移ボタン
    - リンク期限切れ時のエラーメッセージと再送信リンク

## 顧客マイページ

### 予約一覧ページ

- **目的**: 自分の予約を一覧で管理する
- **機能**:
    - 「今後の予約」「過去の予約」のタブ切り替え
    - 予約カードの一覧表示（ステータスバッジ、店舗名、メニュー名、担当スタッフ名、予約日時）
    - 予約詳細ページへの遷移
    - 完了済み予約からの再予約
    - ページネーション

### 予約詳細ページ

- **目的**: 予約の詳細情報を確認し、変更・キャンセル操作を行う
- **機能**:
    - 予約情報の表示（ステータス、店舗名、メニュー名、所要時間、料金、担当スタッフ名、予約日時、備考）
    - ステータスに応じたアクション（変更・キャンセル・再予約）
    - キャンセル確認（理由選択を含む）

### 予約変更ページ

- **目的**: 既存の予約内容を変更する
- **機能**:
    - 現在の予約内容をプリセットしたステップ形式フォーム
    - メニュー・スタッフ・日時の変更
    - 変更前後の差分表示
    - 変更確定

### 通知一覧ページ

- **目的**: すべての通知を時系列で確認する
- **機能**:
    - 通知の一覧表示（通知タイプアイコン、メッセージ概要、受信日時）
    - 未読/既読の視覚的区別
    - 「すべて既読にする」ボタン
    - 通知種類によるフィルタリング（すべて / 予約関連 / お知らせ）
    - 通知クリックで関連ページへの遷移
    - ページネーション

### プロフィール設定ページ

- **目的**: 顧客アカウントのプロフィール情報を管理する
- **機能**:
    - プロフィール編集フォーム（表示名、メールアドレス、電話番号）
    - パスワード変更セクション（現在のパスワード、新しいパスワード、確認用パスワード）
    - アカウント削除（確認モーダル、パスワード入力、未来予約がある場合の警告）

### 通知設定ページ

- **目的**: 通知の受信設定を管理する
- **機能**:
    - メール通知のON/OFF設定（通知種別ごと）
    - アプリ内通知のON/OFF設定（通知種別ごと）
    - 自動保存

## 管理画面共通ページ

### テナント選択ページ

- **目的**: 複数テナントに所属する場合に操作対象のテナントを選択する
- **機能**:
    - 所属テナントのカード一覧表示（テナント名、自分のロール）
    - テナント選択によるダッシュボードへの遷移
    - テナント未所属時のテナント新規登録・招待待ち案内

### 招待一覧ページ

- **目的**: 受け取った招待を管理する
- **機能**:
    - 未対応招待のカード一覧表示（テナント名、招待日時、招待者名、ロール）
    - 招待の承認・辞退操作（確認モーダル付き）
    - 招待がない場合の案内メッセージ

### メンバープロフィール設定ページ

- **目的**: テナントメンバーとしてのアカウント情報を管理する
- **機能**:
    - プロフィール編集フォーム（氏名、メールアドレス、電話番号）
    - パスワード変更セクション
    - アカウント削除（確認モーダル、唯一の管理者の場合の警告）

### 管理画面通知一覧ページ

- **目的**: 管理画面の通知を時系列で確認する
- **機能**:
    - 通知の一覧表示（通知タイプアイコン、メッセージ概要、受信日時）
    - 未読/既読の視覚的区別
    - 「すべて既読にする」ボタン
    - 通知種類によるフィルタリング（すべて / 予約関連 / メンバー関連 / お知らせ）
    - ページネーション

### 管理画面通知設定ページ

- **目的**: 管理画面の通知受信設定を管理する
- **機能**:
    - メール通知のON/OFF設定（通知種別ごと、ロールに応じた表示）
    - アプリ内通知のON/OFF設定
    - 自動保存

## テナント管理者ページ

### 管理者ダッシュボード

- **目的**: テナントの概況を一覧し、主要な操作への導線を提供する
- **機能**:
    - 承認待ち予約件数の通知バナー
    - 未対応招待の通知バナー
    - 初期セットアップガイド（テナント新規登録直後のみ）
    - 当日の予約サマリー

### テナント新規登録ページ

- **目的**: 新しいテナント（店舗）を登録する
- **機能**:
    - ステップ1: 基本情報入力（テナント名、カテゴリー、URLパス）
    - ステップ2: 所在地・連絡先入力（郵便番号、住所、電話番号）
    - ステップ3: 確認
    - URLパスのリアルタイム使用可否チェック
    - 郵便番号による住所自動補完

### テナント情報設定ページ

- **目的**: テナントの基本情報を管理する
- **機能**:
    - テナント情報編集フォーム（テナント名、カテゴリー、URLパス、住所、電話番号、紹介文、店舗画像）
    - URLパスのリアルタイム使用可否チェック
    - 画像のアップロード・並び替え・削除（最大10枚）
    - テナント削除（確認モーダル、テナント名入力による確認）

### メンバー管理ページ

- **目的**: テナントのメンバーと招待を管理する
- **機能**:
    - 「メンバー」「招待」のタブ切り替え
    - メンバー一覧表示（メンバー名、メールアドレス、ロールバッジ、参加日）
    - メンバーのロール変更・削除操作
    - ロールフィルター
    - 招待の送信（メールアドレス、ロール指定）
    - 招待一覧表示（メールアドレス、ロール、ステータスバッジ、招待日時）
    - 招待の取り消し・再送信

### 営業設定ページ

- **目的**: テナントの営業時間・休業日を管理する
- **機能**:
    - 営業時間の表示・編集（曜日ごとの開始/終了時刻、営業/休業トグル）
    - 定休日の表示・編集（曜日ごとのチェックボックス）
    - 臨時休業日の表示・追加・削除（日付、理由）
    - 各セクションのインライン編集モード

### メニュー管理ページ

- **目的**: テナントが提供するメニューを一覧管理する
- **機能**:
    - メニュー一覧表示（メニュー名、カテゴリー、所要時間、料金）
    - カテゴリーフィルター
    - メニューの並び順変更（ドラッグ&ドロップ）
    - メニュー登録・編集ページへの遷移
    - メニュー削除（確認モーダル、関連予約の警告）

### メニュー登録・編集ページ

- **目的**: メニューの詳細情報を登録・編集する
- **機能**:
    - メニュー情報入力フォーム（メニュー名、カテゴリー、説明文、所要時間、料金）
    - バリデーションエラーのインライン表示

### スタッフ管理ページ

- **目的**: テナントのスタッフを一覧管理する
- **機能**:
    - スタッフ一覧表示（プロフィール画像、スタッフ名、担当メニュー数）
    - スタッフ詳細ページへの遷移
    - スタッフ未登録時の案内メッセージ

### スタッフ詳細ページ

- **目的**: スタッフのプロフィールと担当メニューを管理する
- **機能**:
    - プロフィール編集セクション（スタッフ表示名、プロフィール画像、自己紹介文）
    - 担当メニュー設定セクション（チェックボックスリストによるインライン編集）

### シフト管理ページ

- **目的**: スタッフのシフトをカレンダー形式で管理する
- **機能**:
    - シフトカレンダー表示（週表示/月表示の切り替え）
    - スタッフフィルター
    - シフトの登録（スタッフ、日付、開始/終了時刻、繰り返し設定）
    - シフトの編集・削除（繰り返しシフトの個別/一括変更対応）
    - シフト希望の表示（薄い色の背景）
    - 予約との競合警告

### 予約設定ページ

- **目的**: 予約に関する各種設定を管理する
- **機能**:
    - 設定の表示・インライン編集
    - 予約受付期間の設定
    - 予約受付締切の設定
    - キャンセル期限の設定
    - 予約枠の時間単位の設定
    - 予約間バッファ時間の設定
    - 予約承認方法の設定（自動承認/手動承認）

### 予約管理ページ（管理者）

- **目的**: テナントの全予約を一覧管理する
- **機能**:
    - リスト表示/カレンダー表示の切り替え
    - リスト: 予約一覧表示（ステータスバッジ、顧客名、メニュー名、担当スタッフ名、予約日時）
    - カレンダー: 週表示カレンダー（時間帯×日付、ステータス色分け）
    - フィルター（ステータス、スタッフ、日付範囲）
    - 承認待ち予約の通知バナー
    - 予約詳細ページへの遷移
    - 代理予約登録ページへの遷移
    - ページネーション

### 予約詳細ページ（管理者）

- **目的**: 予約の詳細情報を確認し、承認・変更・キャンセル等の操作を行う
- **機能**:
    - 予約情報の表示（ステータス、顧客情報、メニュー、所要時間、料金、担当スタッフ、予約日時、備考）
    - ステータスに応じたアクション（承認/却下、変更、キャンセル）
    - 却下時の理由入力
    - キャンセル時の理由入力

### 代理予約登録ページ（管理者）

- **目的**: 管理者が顧客に代わって予約を登録する
- **機能**:
    - 顧客情報入力（既存顧客検索 or 新規入力）
    - メニュー選択
    - スタッフ選択（選択メニューの担当スタッフのみ）
    - 日時選択（空き時間枠から選択）
    - 備考入力

### 予約変更ページ（管理者）

- **目的**: 管理者が予約内容を変更する
- **機能**:
    - 現在の予約内容をプリセットしたフォーム
    - メニュー・スタッフ・日時の変更
    - 変更前後の差分表示

## スタッフページ

- **機能**:
    - 今日のスケジュール（タイムライン形式でシフトと予約を表示）
    - 今日の予約一覧
    - 未対応招待の通知バナー

- **目的**: 顧客向けに公開されるスタッフプロフィールを編集する
- **機能**:
    - プロフィール編集フォーム（スタッフ表示名、プロフィール画像、自己紹介文）

### 担当メニューページ

- **目的**: 自分が担当するメニューを確認する
- **機能**:
    - 担当メニューのカード一覧表示（メニュー名、カテゴリー、所要時間、料金、説明）
    - メニュー詳細の表示
    - 担当メニュー未設定時の案内メッセージ

### スケジュールページ

- **目的**: 自分のシフトと予約をカレンダー形式で確認する

    - シフトカレンダー表示（週表示/月表示の切り替え）

- **目的**: 自分が担当する予約を一覧管理する
- **機能**:
    - リスト表示/カレンダー表示の切り替え
    - リスト: 予約一覧表示（ステータスバッジ、顧客名、メニュー名、予約日時）
    - カレンダー: 週表示カレンダー（自分の予約のみ）
    - フィルター（ステータス、日付範囲）
    - 予約詳細ページへの遷移
    - 代理予約登録ページへの遷移
    - ページネーション

### 予約詳細ページ（スタッフ）

- **目的**: 担当予約の詳細を確認し、変更・キャンセル操作を行う
- **機能**:
    - 予約情報の表示（ステータス、顧客名、電話番号、メニュー、所要時間、料金、予約日時、備考）
    - ステータスに応じたアクション（変更・キャンセル）
    - メールアドレスは非表示

### 代理予約登録ページ（スタッフ）

- **目的**: スタッフが顧客に代わって自分の予約を登録する
- **機能**:
    - 顧客情報入力（既存顧客検索 or 新規入力、名前・電話番号のみ）
    - メニュー選択（自分の担当メニューのみ）
    - 日時選択（自分のシフト内の空き時間枠から選択）
    - 備考入力

### 予約変更ページ（スタッフ）

- **目的**: スタッフが自分の担当予約を変更する
- **機能**:
    - 現在の予約内容をプリセットしたフォーム
    - メニュー変更（自分の担当メニュー内）
    - 日時変更（自分のシフト内）
    - 担当スタッフは変更不可
    - 変更前後の差分表示

## プラットフォーム管理画面

### プラットフォームログインページ

- **目的**: プラットフォーム管理者としてログインする
- **機能**:
    - ログインフォーム（メールアドレス、パスワード）
    - 認証エラーメッセージの表示
    - パスワードリセットページへのリンク

### プラットフォームパスワードリセットページ

- **目的**: プラットフォーム管理者のパスワードリセット用メールを送信する
- **機能**:
    - メールアドレス入力フォーム
    - リセットメール送信完了メッセージの表示

### プラットフォームパスワード再設定ページ

- **目的**: プラットフォーム管理者の新しいパスワードを設定する
- **機能**:
    - 新しいパスワードと確認用パスワードの入力フォーム
    - 変更完了メッセージの表示

### プラットフォームダッシュボード

- **目的**: プラットフォーム全体の概況を把握する
- **機能**:
    - テナント総数、ユーザー総数などのサマリー
    - テナント管理・ユーザー管理への導線

### テナント管理ページ（プラットフォーム）

- **目的**: 全テナントを一覧管理する
- **機能**:
    - テナント一覧表示（テナント名、カテゴリー、ステータスバッジ、メンバー数、登録日）
    - キーワード検索、ステータスフィルター、カテゴリーフィルター
    - テナント詳細ページへの遷移
    - ページネーション

### テナント詳細ページ（プラットフォーム）

- **目的**: テナントの詳細情報を確認し、停止・再開・削除操作を行う
- **機能**:
    - 基本情報の表示（テナント名、カテゴリー、URLパス、住所、電話番号、ステータス、登録日）
    - メンバー一覧の表示
    - 統計情報の表示（メニュー数、総予約数、今月の予約数）
    - テナントの停止・再開操作（確認モーダル、理由入力）
    - テナントの削除操作（確認モーダル、テナント名入力による確認）

### ユーザー管理ページ（プラットフォーム）

- **目的**: 全顧客アカウントを一覧管理する
- **機能**:
    - 顧客一覧表示（顧客名、メールアドレス、ステータスバッジ、登録日、最終ログイン日）
    - キーワード検索、ステータスフィルター
    - 顧客詳細ページへの遷移
    - ページネーション

### ユーザー詳細ページ（プラットフォーム）

- **目的**: 顧客アカウントの詳細を確認し、停止・再開・削除操作を行う
- **機能**:
    - 基本情報の表示（顧客名、メールアドレス、電話番号、ステータス、登録日、最終ログイン日）
    - 予約履歴の表示（総予約数、直近の予約一覧）
    - アカウントの停止・再開操作（確認モーダル、理由入力）
    - アカウントの削除操作（確認モーダル、「削除」入力による確認）
