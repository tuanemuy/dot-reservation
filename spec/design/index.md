# デザイン方針

## トーン・雰囲気

Clean Minimal をベースとした、洗練されつつも温かみのあるデザイン。

- **洗練**: 広い余白、控えめなシャドウ、整理されたタイポグラフィで信頼感を演出
- **温かみ**: Sage Green + Rose + Warm Gold のカラーパレットで、サービス業としての親しみやすさを表現
- **抑制**: 装飾を最小限に抑え、コンテンツそのものが主役になるレイアウト

## カラーの使い分け

| ロール | 色 | 主な用途 |
|--------|-----|---------|
| **Primary** | Sage Green | CTA、リンク、アクティブタブ、カテゴリバッジ |
| **Secondary** | Rose | 人気バッジ、スタッフアバター背景、ステータス表示の一部 |
| **Accent** | Warm Gold | 価格表示、通知インジケーター、おすすめバッジ |
| **Neutral** | ウォームグレー | テキスト、背景、ボーダー |
| **Semantic** | 各色 | Success=確定、Warning=承認待ち、Error=キャンセル/エラー |

## レイアウトの原則

- **グリッド**: 1280px max-width、左右 40px パディング
- **余白**: セクション間は `--space-section` (80px)、要素間は `--space-md` (16px) 〜 `--space-lg` (24px) を基本
- **対称性**: 基本は対称レイアウト。ヒーローは2カラムグリッド
- **カード**: `--radius-lg` (14px) の角丸、1px ボーダー、ホバー時に軽いシャドウ

## インタラクション方針

- **ホバー**: 背景色の変化 + `--transition-default` (0.15s ease)。シャドウは控えめに
- **フォーカス**: `outline: 2px solid var(--color-primary)` + `outline-offset: 2px`
- **ボタン押下**: `transform: scale(0.99)` + `--transition-fast` (0.1s)
- **ページ遷移**: 特別なアニメーションは設けない (React Router のデフォルト)

## 画像・アイコン方針

- **アイコン**: Heroicons (outline スタイル)、stroke-width: 1.5、サイズは 16-20px
- **画像**: `--radius-xl` (16px) の角丸でクリップ
- **アバター**: 円形 (`--radius-full`)、画像がない場合は名前の頭文字 + Secondary カラーグラデーション背景

## アクセシビリティ

- コントラスト比: WCAG AA 準拠 (4.5:1 以上)
- フォーカスインジケーター: すべてのインタラクティブ要素に visible focus ring
- フォントサイズ: 本文 13px 以上

## 避けるパターン

- カードの左側にアクセントカラーのボーダーを付ける表現 (AIが生成しがちなパターン)
- 過度な装飾グラデーション
- 意味のないアニメーション

## スコープ外

- ダークモード対応
- レスポンシブ対応 (Phase 3 ではデスクトップのみ)
- マイクロインタラクション / アニメーション詳細
