# レビュー Round 3: /audit (アクセシビリティ)

## HIGH (必須修正)

### A1. neutral-400 テキストのコントラスト不足
- **問題**: neutral-400 (#B8B5B1) の白背景でのコントラスト比 ~2.4:1（WCAG AA 4.5:1 未満）
- **該当**: サイドバーセクションラベル、フッター著作権テキスト、メタラベル等（全ページ横断）
- **対応**: 可読テキストに使われている neutral-400 を neutral-500 に変更

### A2. フォーム入力の focus 表示が不十分
- **問題**: outline: none + box-shadow 0.1 opacity が事実上見えない（20+ファイル）
- **対応**: outline: 2px solid var(--color-primary); outline-offset: 2px に統一

### A3. モーダルの ARIA 属性不足
- **該当**: admin-menus.html, admin-reservation-detail.html
- **対応**: role="dialog" aria-modal="true" aria-labelledby を追加

### A4. ラベルなしフォーム要素（実装時対応）
- **問題**: select 34個、checkbox 19個、input多数、textarea 3個に aria-label なし
- **対応**: これらはデザインモックアップの範囲を超える。実装時に適切な label/aria-label を付与する。レビュー記録として残す。

## MEDIUM (実装時対応)

### A5. プレースホルダーのコントラスト
- **対応**: neutral-400 → neutral-500 に変更（A1 と同時に対応）

### A6. 見出しレベルのスキップ
- **該当**: admin-menus, search-results, staff-menus (h1 → h3)
- **対応**: 実装時に適切な見出し階層にする

### A7. top.html に main 要素がない
- **対応**: main 要素で囲む

### A8. form 要素の欠落（23ファイル）
- **対応**: 実装時に form 要素で囲む
