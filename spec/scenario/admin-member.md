# テナント管理者 - メンバー管理

## メンバーを招待する

### トリガー

- メンバー管理ページの「メンバーを招待」ボタンをクリック

### フロー

1. 管理画面サイドバーの「メンバー管理」をクリックし、メンバー管理ページに遷移する
2. 「メンバーを招待」ボタンをクリックする
3. 招待モーダルが表示される
    - メールアドレスを入力する
    - ロールをドロップダウンで選択する（管理者 / スタッフ）
    - 「招待を送信」ボタンをクリックする
4. 招待メールが送信される
5. トースト通知で「招待メールを送信しました」と表示する
6. モーダルが閉じ、招待一覧に新しい招待が「承認待ち」ステータスで追加される

### 補足

- 既にメンバーであるメールアドレスを入力した場合、インラインでエラーメッセージを表示する
- 既にテナントメンバーアカウントを持っていない場合でも招待は可能（招待メール内にアカウント登録リンクを含める）
- 招待の有効期限は7日間とする

---

## 招待の一覧を閲覧する

### トリガー

- メンバー管理ページの「招待」タブをクリック

### フロー

1. メンバー管理ページには2つのタブがある
    - **メンバー**（デフォルト）
    - **招待**
2. 「招待」タブをクリックする
3. 招待の一覧がテーブル形式で表示される
    - 各行には以下を表示する
        - 招待先メールアドレス
        - ロール
        - ステータス（承認待ち / 承認済み / 辞退 / 期限切れ）
        - 招待日時
    - ステータスに応じた色のバッジを表示する
4. 「承認待ち」の招待にはアクションメニュー（三点リーダー）を表示する
    - 「招待を取り消す」
    - 「招待を再送信する」

### 補足

- 期限切れの招待は「招待を再送信する」で新しい招待を送信できる
- 招待を取り消す場合、確認モーダルで確認する

## メンバーのロールを変更する

### トリガー

- メンバー管理ページの「メンバー」タブで、対象メンバーのアクションメニューから「ロールを変更」を選択

### フロー

1. メンバー管理ページの「メンバー」タブで、メンバー一覧を表示する
2. 対象メンバーの行のアクションメニュー（三点リーダー）をクリックする
3. ドロップダウンメニューから「ロールを変更」を選択する
4. ロール変更モーダルが表示される
    - 現在のロールが表示される
    - 新しいロールをドロップダウンで選択する（管理者 / スタッフ）
    - 「変更する」ボタンをクリックする
5. トースト通知で「ロールを変更しました」と表示する
6. メンバー一覧のロール表示が更新される

### 補足

- 自分自身のロールは変更できない（自分をスタッフに降格して管理者がいなくなることを防ぐ）
- ロール変更後、対象メンバーに通知が送信される
- 唯一の管理者を変更しようとした場合、エラーメッセージを表示する

---

## メンバーを削除する

### トリガー

- メンバー管理ページの「メンバー」タブで、対象メンバーのアクションメニューから「メンバーを削除」を選択

### フロー

1. 対象メンバーの行のアクションメニュー（三点リーダー）をクリックする
2. ドロップダウンメニューから「メンバーを削除」を選択する
3. 確認モーダルが表示される
    - 「[メンバー名] をこのテナントから削除しますか？」というメッセージ
    - 担当予約がある場合、「担当している未来の予約が○件あります。削除後、これらの予約は担当者未定になります。」と警告を表示する
    - 「削除する」ボタン（赤色）と「キャンセル」ボタン
4. 「削除する」ボタンをクリックする
5. トースト通知で「メンバーを削除しました」と表示する
6. メンバー一覧から対象メンバーが消える

### 補足

- 自分自身を削除することはできない
- テナント唯一の管理者は削除できない
- 削除されたメンバーに通知が送信される
- メンバーのアカウント自体は削除されない（テナントからの除名のみ）

---

## メンバーの一覧を閲覧する

### トリガー

- 管理画面サイドバーの「メンバー管理」をクリック

### フロー

1. メンバー管理ページに遷移し、「メンバー」タブがデフォルトで表示される
2. メンバー一覧がテーブル形式で表示される
    - 各行には以下を表示する
        - メンバー名
        - メールアドレス
        - ロール（管理者 / スタッフ）のバッジ
        - 参加日
        - アクションメニュー（三点リーダー）
3. ロールでフィルタリングできるドロップダウンをテーブル上部に配置する
    - すべて / 管理者 / スタッフ

### 補足

- 自分自身の行には「（あなた）」ラベルを表示する
