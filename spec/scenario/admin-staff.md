# テナント管理者 - スタッフ管理

## スタッフの一覧を閲覧する

### トリガー

- 管理画面サイドバーの「スタッフ管理」をクリック

### フロー

1. スタッフ管理ページに遷移する
2. スタッフの一覧がテーブル形式で表示される
    - 各行には以下を表示する
        - プロフィール画像（小さなアバター）
        - スタッフ名
        - 担当メニュー数
        - アクションメニュー（三点リーダー）
3. スタッフが0件の場合、「スタッフが登録されていません。メンバーをスタッフロールで招待してください。」というメッセージを表示する

### 補足

- スタッフ一覧にはスタッフロールのメンバーが表示される
- スタッフの追加はメンバー管理でスタッフロールとして招待することで行う

## スタッフのプロフィールを編集する

### トリガー

- スタッフ管理ページのスタッフ行をクリック
- スタッフ行のアクションメニューから「プロフィールを編集」を選択

### フロー

1. スタッフ管理ページでスタッフ行をクリック、またはアクションメニュー（三点リーダー）から「プロフィールを編集」を選択する
2. スタッフ詳細ページに遷移する
3. プロフィールセクションが表示される
    - 現在の情報がフォームにプリフィルされた状態で表示される
        - スタッフ表示名（顧客向けに表示される名前）
        - プロフィール画像（アップロード、プレビュー表示）
        - 自己紹介文（テキストエリア）
4. 必要な項目を編集する
5. 「保存」ボタンをクリックする
6. トースト通知で「スタッフプロフィールを更新しました」と表示する

### 補足

- このプロフィールは顧客向けに公開される情報
- メンバーのアカウント情報とは別の情報体系

## スタッフの担当メニューを設定する

### トリガー

- スタッフ詳細ページの「担当メニュー」セクションの「編集」ボタンをクリック

### フロー

1. スタッフ詳細ページの「担当メニュー」セクションには、現在の担当メニューが一覧表示される
2. 「編集」ボタンをクリックする
3. セクションがインラインで編集モードに切り替わる
    - 登録済みのすべてのメニューがチェックボックスリストで表示される
    - 現在担当しているメニューにはチェックが入っている
4. チェックボックスを切り替えて担当メニューを設定する
5. 「保存」ボタンをクリックする
6. トースト通知で「担当メニューを更新しました」と表示する
7. 表示モードに戻り、更新された担当メニュー一覧が表示される

### 補足

- 担当メニューを0件にすることも可能（予約時にスタッフ候補として表示されなくなる）
- 担当メニューの変更は新しい予約から反映される（既存の予約には影響しない）
