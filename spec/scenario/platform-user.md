# プラットフォーム管理者 - ユーザー管理

## 顧客アカウントの一覧を閲覧する

### トリガー

- プラットフォーム管理画面サイドバーの「ユーザー管理」をクリック

### フロー

1. ユーザー管理ページに遷移する
2. 顧客アカウントの一覧がテーブル形式で表示される
    - 各行には以下を表示する
        - 顧客名
        - メールアドレス
        - ステータスのバッジ（アクティブ / 停止中）
        - 登録日
        - 最終ログイン日
        - アクションメニュー（三点リーダー）
3. テーブル上部にフィルター・検索機能を配置する
    - キーワード検索（名前、メールアドレスで検索）
    - ステータスフィルター（ドロップダウン: すべて / アクティブ / 停止中）
4. ページネーション対応
5. デフォルトでは登録日が新しい順に表示する

---

## 顧客アカウントの詳細を閲覧する

### トリガー

- ユーザー一覧の顧客行をクリック

### フロー

1. 顧客詳細ページに遷移する
2. 以下の情報をセクションごとに表示する
    - **基本情報**セクション
        - 顧客名
        - メールアドレス
        - 電話番号
        - ステータス（アクティブ / 停止中）
        - 登録日
        - 最終ログイン日
    - **予約履歴**セクション
        - 総予約数
        - 直近の予約一覧（テーブル: 店舗名、メニュー名、日時、ステータス）
        - 「すべての予約を見る」リンク（フィルター付きの予約一覧に遷移）
3. ページ上部にステータスに応じたアクションボタンを表示する
    - アクティブ:「アカウントを停止」ボタン
    - 停止中:「アカウントを再開」ボタン
4. ページ下部に「アカウントを削除」ボタン（赤色テキスト）を表示する

---

## 顧客アカウントを停止する

### トリガー

- 顧客詳細ページの「アカウントを停止」ボタンをクリック
- ユーザー一覧のアクションメニューから「停止する」を選択

### フロー

1. 「アカウントを停止」ボタンをクリックする
2. 確認モーダルが表示される
    - 「[顧客名] のアカウントを停止しますか？停止すると、ログインおよび新規予約ができなくなります。」というメッセージ
    - 停止理由を入力するテキストエリア（任意）
    - 「停止する」ボタン（赤色）と「キャンセル」ボタン
3. 「停止する」ボタンをクリックする
4. アカウントのステータスが「停止中」に変更される
5. トースト通知で「アカウントを停止しました」と表示する

### 補足

- 停止中のアカウントはログインできなくなる
- 既存の予約はキャンセルされない
- 停止理由はシステム内に記録される

## 顧客アカウントを再開する

### トリガー

- 顧客詳細ページの「アカウントを再開」ボタンをクリック
- ユーザー一覧のアクションメニューから「再開する」を選択

### フロー

1. 「アカウントを再開」ボタンをクリックする
2. 確認モーダルが表示される
    - 「[顧客名] のアカウントを再開しますか？」というメッセージ
    - 「再開する」ボタンと「キャンセル」ボタン
3. 「再開する」ボタンをクリックする
4. アカウントのステータスが「アクティブ」に変更される
5. トースト通知で「アカウントを再開しました」と表示する

---

## 顧客アカウントを削除する

### トリガー

- 顧客詳細ページ下部の「アカウントを削除」ボタンをクリック

### フロー

1. 「アカウントを削除」ボタン（赤色テキスト）をクリックする
2. 確認モーダルが表示される
    - 「[顧客名] のアカウントを完全に削除しますか？この操作は元に戻せません。」というメッセージ
    - 未来の予約がある場合、「未来の予約が○件あります。」と警告を表示する
    - 確認のため「削除」と入力するテキストフィールドを表示する
    - 「削除する」ボタン（赤色）と「キャンセル」ボタン
3. 「削除」と入力し、「削除する」ボタンをクリックする
4. アカウントが削除され、ユーザー一覧ページにリダイレクトする
5. トースト通知で「アカウントを削除しました」と表示する

### 補足

- 未来の予約がある場合、予約は自動キャンセルされ、関連するテナントに通知が送信される
- 削除された顧客の過去の予約データは匿名化されて保持される
