# 顧客 - 予約

## メニュー・担当スタッフ・日時を選択して予約する

### トリガー

- 店舗詳細ページの「予約する」CTAボタンをクリック
- メニュー詳細モーダルの「このメニューで予約する」ボタンをクリック
- スタッフ詳細モーダルの「このスタッフで予約する」ボタンをクリック

### フロー

1. 予約ページに遷移する（ステップ形式のフォーム）
2. **ステップ1: メニュー選択**
    - メニュー一覧がカード形式で表示される（メニュー名、所要時間、料金）
    - メニューを1つ選択する（ラジオボタン式、選択中のカードはハイライト）
    - 遷移元で既にメニューが選択されている場合はプリセットされる
    - 「次へ」ボタンをクリックする
3. **ステップ2: スタッフ選択**
    - 選択したメニューを担当できるスタッフの一覧が表示される
    - 「指名なし（誰でもOK）」オプションを先頭に表示する
    - 各スタッフカードにはアバター、スタッフ名を表示する
    - スタッフを1人選択する
    - 遷移元で既にスタッフが選択されている場合はプリセットされる
    - 「次へ」ボタンをクリックする（「戻る」ボタンも表示）
4. **ステップ3: 日時選択**
    - カレンダー形式で日付を選択する
        - 予約可能な日付は通常表示、予約不可の日付（定休日、受付期間外）はグレーアウト
        - 今日の日付をハイライト表示
    - 日付を選択すると、その日の空き時間枠が一覧表示される
        - 空き枠は時間帯のボタンとして表示（例: 10:00、10:30、11:00...）
        - 空きなしの枠はグレーアウト
        - 「指名なし」の場合、いずれかのスタッフに空きがあれば選択可能
    - 時間枠を1つ選択する
    - 「次へ」ボタンをクリックする
5. **ステップ4: 確認**
    - 予約内容の確認画面を表示する
        - 店舗名
        - メニュー名、所要時間、料金
        - 担当スタッフ名（指名なしの場合はその旨表示）
        - 予約日時
    - 備考欄（テキストエリア、任意入力）
    - 未ログインの場合、この時点でログイン/新規登録を求める
        - 「ログインして予約する」「新規登録して予約する」ボタンを表示
        - ログイン/新規登録後に確認画面に戻る（選択内容は保持）
    - 「予約を確定する」ボタンをクリックする
6. **完了画面**
    - 予約完了メッセージを表示する
        - 自動承認の場合:「予約が確定しました」
        - 手動承認の場合:「予約リクエストを送信しました。店舗からの承認をお待ちください。」
    - 予約内容のサマリーを表示する
    - 「予約一覧を見る」「店舗ページに戻る」ボタンを表示する

### 補足

- ステップインジケーター（1. メニュー → 2. スタッフ → 3. 日時 → 4. 確認）をページ上部に常に表示する
- 各ステップで「戻る」ボタンにより前のステップに戻れる（選択内容は保持）
- 予約確定時に確認メールを送信する
- 「指名なし」を選択した場合、空きのあるスタッフが自動的に割り当てられる

## 空き状況を確認する

### トリガー

- 予約フローのステップ3（日時選択）で自動的に表示される

### フロー

1. 予約フローのステップ3でカレンダーから日付を選択する
2. 選択した日付の空き時間枠がカレンダー下部にリスト表示される
    - 空き枠: 選択可能なボタンとして表示
    - 予約済み枠: グレーアウトで表示
    - 営業時間外: 表示しない
3. カレンダー上で予約可能な日付には空き枠の数を小さく表示する（例:「残3」）
4. 月を切り替えて別の月の空き状況も確認できる

### 補足

- 空き状況はリアルタイムで取得する
- 予約確定時に既に他のユーザーに予約された場合は、エラーメッセージを表示して日時選択ステップに戻す

## 自分の予約一覧を閲覧する

### トリガー

- ヘッダーのユーザーアイコン > ドロップダウンメニュー >「予約一覧」をクリック
- マイページのサイドメニューから「予約一覧」をクリック

### フロー

1. 予約一覧ページに遷移する
2. タブで表示を切り替える
    - **今後の予約**（デフォルト表示）
    - **過去の予約**
3. 「今後の予約」タブ
    - 予約日時が近い順に表示する
    - 各予約カードには以下を表示する
        - 予約ステータスのバッジ（確定、承認待ち）
        - 店舗名
        - メニュー名
        - 担当スタッフ名
        - 予約日時
    - 予約カードをクリックすると予約詳細ページに遷移する
4. 予約がない場合、「今後の予約はありません」というメッセージを表示する

### 補足

- 予約カードにはステータスに応じた色のバッジを表示する（確定: 緑、承認待ち: 黄）

## 予約履歴を閲覧する

### トリガー

- 予約一覧ページの「過去の予約」タブを選択

### フロー

1. 予約一覧ページの「過去の予約」タブを選択する
2. 予約日時が新しい順に表示する
3. 各予約カードには以下を表示する
    - 予約ステータスのバッジ（完了、キャンセル済み）
    - 店舗名
    - メニュー名
    - 担当スタッフ名
    - 予約日時
4. 予約カードをクリックすると予約詳細ページに遷移する
5. ページネーションで過去の予約を遡って閲覧できる

### 補足

- 完了した予約からは「再予約する」ボタンで同じ店舗・メニューの予約フローに遷移できる

## 予約の詳細を閲覧する

### トリガー

- 予約一覧ページの予約カードをクリック
- 通知から予約詳細へのリンクをクリック

### フロー

1. 予約詳細ページに遷移する
2. 以下の情報を表示する
    - 予約ステータス（確定、承認待ち、完了、キャンセル済み）
    - 店舗名（店舗詳細ページへのリンク付き）
    - メニュー名
    - 所要時間
    - 料金
    - 担当スタッフ名
    - 予約日時
    - 備考
    - 予約日時（登録日時）
3. 予約ステータスに応じたアクションボタンを表示する
    - 確定・承認待ちの予約:「予約を変更する」「予約をキャンセルする」ボタン
    - 完了の予約:「再予約する」ボタン
    - キャンセル済みの予約: アクションボタンなし

## 予約を変更する

### トリガー

- 予約詳細ページの「予約を変更する」ボタンをクリック

### フロー

1. 予約詳細ページの「予約を変更する」ボタンをクリックする
2. 予約変更ページに遷移する（予約フローと同様のステップ形式）
    - 現在の予約内容がプリセットされた状態で表示する
    - メニュー、スタッフ、日時を変更できる
3. 変更内容を確認する画面で、変更前と変更後の差分をハイライトして表示する
4. 「変更を確定する」ボタンをクリックする
5. 変更完了メッセージを表示する
    - 自動承認の場合:「予約を変更しました」
    - 手動承認の場合:「予約変更リクエストを送信しました」
6. 予約詳細ページにリダイレクトする

### 補足

- キャンセル期限を過ぎている場合は「予約を変更する」ボタンを非表示にする
- 変更確定時に確認メールを送信する

---

## 予約をキャンセルする

### トリガー

- 予約詳細ページの「予約をキャンセルする」ボタンをクリック

### フロー

1. 予約詳細ページの「予約をキャンセルする」ボタンをクリックする
2. 確認モーダルが表示される
    - 「本当にこの予約をキャンセルしますか？」というメッセージ
    - 予約内容のサマリー（店舗名、メニュー名、日時）
    - キャンセル理由の選択（ドロップダウン）
        - 都合が悪くなった
        - 別の日に変更したい
        - その他
    - 「キャンセルする」ボタン（赤色）と「戻る」ボタン
3. 「キャンセルする」ボタンをクリックする
4. キャンセル完了メッセージをトースト通知で表示する
5. 予約詳細ページに戻り、ステータスが「キャンセル済み」に更新される

### 補足

- キャンセル期限を過ぎている場合は「予約をキャンセルする」ボタンを非表示にする
- キャンセル確定時にキャンセル確認メールを送信する
- 店舗側にもキャンセル通知を送信する
