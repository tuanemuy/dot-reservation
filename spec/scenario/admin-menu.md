# テナント管理者 - メニュー管理

## メニューを登録する

### トリガー

- メニュー管理ページの「メニューを追加」ボタンをクリック

### フロー

1. 管理画面サイドバーの「メニュー管理」をクリックし、メニュー管理ページに遷移する
2. 「メニューを追加」ボタンをクリックする
3. メニュー登録ページに遷移する
4. 登録フォームに以下を入力する
    - メニュー名
    - カテゴリー（ドロップダウン。カテゴリーはテキスト入力で新規追加も可能）
    - 説明文（テキストエリア）
    - 所要時間（ドロップダウン、15分単位で選択）
    - 料金
5. バリデーションエラーがあればフィールド直下にインラインでエラーメッセージを表示する
6. 「登録する」ボタンをクリックする
7. トースト通知で「メニューを登録しました」と表示する
8. メニュー管理ページにリダイレクトし、新しいメニューが一覧に追加されている

### 補足

- メニュー名は同一テナント内で一意である必要がある
- 登録直後のメニューは「公開」状態となり、顧客から閲覧・予約可能になる

## メニューを編集する

### トリガー

- メニュー管理ページのメニュー行のアクションメニューから「編集」を選択
- メニュー行をクリック

### フロー

1. メニュー管理ページでメニュー行をクリック、またはアクションメニュー（三点リーダー）から「編集」を選択する
2. メニュー編集ページに遷移する
3. 現在の情報がフォームにプリフィルされた状態で表示される
4. 必要な項目を編集する
5. 「保存」ボタンをクリックする
6. トースト通知で「メニューを更新しました」と表示する
7. メニュー管理ページにリダイレクトする

### 補足

- 既に予約が入っているメニューの所要時間を変更する場合、「未来の予約には影響しません。新しい予約から反映されます。」とインラインで注意書きを表示する

## メニューを削除する

### トリガー

- メニュー管理ページのメニュー行のアクションメニューから「削除」を選択

### フロー

1. メニュー行のアクションメニュー（三点リーダー）から「削除」を選択する
2. 確認モーダルが表示される
    - 「[メニュー名] を削除しますか？」というメッセージ
    - 未来の予約がある場合、「このメニューに○件の未来の予約があります。削除しても既存の予約は影響を受けません。」と警告を表示する
    - 「削除する」ボタン（赤色）と「キャンセル」ボタン
3. 「削除する」ボタンをクリックする
4. トースト通知で「メニューを削除しました」と表示する
5. メニュー一覧から対象メニューが消える

### 補足

- 削除されたメニューは新規予約では選択できなくなるが、既存の予約データには影響しない
- 削除ではなく非公開にすることも検討（将来的に）

---

## メニューの一覧を閲覧する

### トリガー

- 管理画面サイドバーの「メニュー管理」をクリック

### フロー

1. メニュー管理ページに遷移する
2. メニューの一覧がテーブル形式で表示される
    - 各行には以下を表示する
        - メニュー名
        - カテゴリー
        - 所要時間
        - 料金
        - アクションメニュー（三点リーダー）
3. カテゴリーでフィルタリングできるドロップダウンをテーブル上部に配置する
4. メニューが0件の場合、「メニューが登録されていません。」というメッセージと「メニューを追加」ボタンを表示する

### 補足

- メニューの並び順はドラッグ&ドロップで変更可能（顧客向けの表示順に反映される）
