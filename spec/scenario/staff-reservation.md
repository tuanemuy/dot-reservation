# スタッフ - 予約管理

## 自分の担当予約一覧を閲覧する

### トリガー

- 管理画面サイドバーの「予約管理」をクリック
- ダッシュボードの「今日の予約」セクションの「もっと見る」をクリック

### フロー

1. 予約管理ページに遷移する
2. 自分が担当する予約のみが表示される
3. 表示形式を切り替えるタブを配置する
    - **リスト表示**（デフォルト）
    - **カレンダー表示**
4. **リスト表示**
    - 予約の一覧がテーブル形式で表示される
    - 各行には以下を表示する
        - 予約ステータスのバッジ（確定、完了、キャンセル済み）
        - 顧客名
        - メニュー名
        - 予約日時
        - アクションメニュー（三点リーダー）
    - テーブル上部にフィルター機能を配置する
        - ステータス（ドロップダウン: すべて / 確定 / 完了 / キャンセル済み）
        - 日付範囲（カレンダーピッカー）
    - デフォルトでは「今日以降の予約」を「予約日時が近い順」に表示する
    - ページネーション対応
5. **カレンダー表示**
    - 週表示のカレンダー（自分の予約のみ）
        - 縦軸: 時間帯
        - 横軸: 日付
        - 予約が色付きブロックで表示される
    - 予約ブロックをクリックすると予約詳細ポップオーバーが表示される

### 補足

- ダッシュボードには「今日の予約」として当日の担当予約一覧を時系列で表示する
- 「指名なし」で登録された予約のうち、自分に割り当てられたものも表示される

## 予約の詳細を閲覧する

### トリガー

- 予約一覧の予約行をクリック
- カレンダー表示の予約ブロックのポップオーバーから「詳細を見る」をクリック

### フロー

1. 予約詳細ページに遷移する
2. 以下の情報を表示する
    - 予約ステータス
    - 顧客情報
        - 顧客名
        - 電話番号
    - 予約内容
        - メニュー名
        - 所要時間
        - 料金
        - 予約日時
        - 備考
3. ステータスに応じたアクションボタンを表示する
    - 確定:「変更する」「キャンセルする」ボタン
    - 完了・キャンセル済み: アクションボタンなし

### 補足

- スタッフには顧客のメールアドレスは表示しない（電話番号のみ表示）
- スタッフは承認待ちの予約を承認/却下する権限はない

## 予約を代理で登録する

### トリガー

- 予約管理ページの「予約を登録」ボタンをクリック

### フロー

1. 「予約を登録」ボタンをクリックする
2. 代理予約登録ページに遷移する
3. 以下の情報を入力する
    - **顧客情報**
        - 既存顧客を検索（名前で検索、ドロップダウンで候補表示）
        - または新規顧客情報を入力（名前、電話番号）
    - **メニュー選択**
        - 自分の担当メニューのみドロップダウンで選択可能
    - **日時選択**
        - 日付をカレンダーピッカーで選択する
        - 自分のシフト内の空き時間枠から時間を選択する
    - **備考**（テキストエリア、任意）
4. 「登録する」ボタンをクリックする
5. 「確定」ステータスで登録される（担当スタッフは自分）
6. トースト通知で「予約を登録しました」と表示する
7. 予約詳細ページにリダイレクトする

### 補足

- スタッフが代理登録する場合、スタッフ選択は自分固定（他のスタッフの予約は登録できない）
- 自分のシフト時間外には予約を登録できない

## 自分の担当予約を変更する

### トリガー

- 予約詳細ページの「変更する」ボタンをクリック

### フロー

1. 予約詳細ページの「変更する」ボタンをクリックする
2. 予約変更ページに遷移する
    - 現在の予約内容がプリフィルされた状態で表示される
    - 変更可能な項目
        - メニュー（自分の担当メニュー内で変更可能）
        - 日時（自分のシフト内で変更可能）
    - 担当スタッフは自分から変更できない
3. 変更内容を確認する画面で、変更前と変更後の差分をハイライトして表示する
4. 「変更を確定する」ボタンをクリックする
5. トースト通知で「予約を変更しました」と表示する
6. 予約詳細ページにリダイレクトする
7. 顧客に予約変更通知が送信される

### 補足

- スタッフが変更できるのは自分の担当予約のみ
- 担当スタッフの変更が必要な場合は管理者に依頼する

---

## 自分の担当予約をキャンセルする

### トリガー

- 予約詳細ページの「キャンセルする」ボタンをクリック

### フロー

1. 予約詳細ページの「キャンセルする」ボタンをクリックする
2. 確認モーダルが表示される
    - 「この予約をキャンセルしますか？」というメッセージ
    - 予約内容のサマリー
    - キャンセル理由を入力するテキストエリア（任意）
    - 「キャンセルする」ボタン（赤色）と「戻る」ボタン
3. 「キャンセルする」ボタンをクリックする
4. 予約ステータスが「キャンセル済み」に変更される
5. トースト通知で「予約をキャンセルしました」と表示する
6. 顧客にキャンセル通知が送信される
7. 管理者にもキャンセル通知が送信される

### 補足

- スタッフがキャンセルできるのは自分の担当予約のみ
- キャンセル理由は管理者にも共有される
