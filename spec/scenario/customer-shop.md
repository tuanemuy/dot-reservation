# 顧客 - 店舗の閲覧

## 店舗を検索する

### トリガー

- トップページの検索バーを使用する
- ヘッダーの検索アイコンをクリックする

### フロー

1. トップページにはメインビジュアルの下に検索バーを配置する
2. 検索バーにキーワード（店舗名、エリア名、メニュー名など）を入力する
3. 検索バーにフォーカスすると、検索オプションが表示される
    - エリア（ドロップダウンで都道府県・市区町村を選択）
    - カテゴリー（ドロップダウンで「整体院」「ジム」「美容院」などを選択）
4. 「検索」ボタンをクリックまたはEnterキーを押すと、検索結果ページに遷移する
5. 検索結果ページに一覧が表示される
    - 各店舗カードには以下を表示する
        - 店舗画像（サムネイル）
        - 店舗名
        - カテゴリー
        - エリア
        - 評価（将来的に実装）
    - 検索結果が0件の場合、「該当する店舗が見つかりませんでした」というメッセージと検索条件の変更を促すテキストを表示する
6. 検索結果ページのサイドバー（モバイルでは上部のフィルターボタンからドロワーで表示）で絞り込みができる
    - エリア
    - カテゴリー
7. ページネーションで追加の結果を閲覧できる

### 補足

- 検索結果はデフォルトで関連度順にソートする
- モバイルではフィルター条件を画面下部からのドロワーで表示する

## 店舗の詳細を閲覧する

### トリガー

- 検索結果ページの店舗カードをクリック
- 直接URLでアクセス（`/{tenant-url-path}` の形式）

### フロー

1. 店舗詳細ページに遷移する
2. ページ構成は以下の通り
    - **ヘッダーセクション**
        - 店舗画像（メイン画像）
        - 店舗名
        - カテゴリー
        - 住所
        - 電話番号
        - 「予約する」ボタン（CTAボタン、目立つ位置に固定表示）
    - **タブセクション**（タブで切り替え）
        - メニュー
        - スタッフ
        - アクセス
        - 店舗情報
3. デフォルトでは「メニュー」タブが選択された状態で表示する
4. モバイルでは「予約する」ボタンを画面下部にフローティング固定表示する

### 補足

- 各タブの内容はページ遷移なしでタブ切り替えにより表示する
- 店舗画像が複数ある場合はカルーセルで表示する

## 店舗が提供するメニューの一覧を閲覧する

### トリガー

- 店舗詳細ページの「メニュー」タブを選択

### フロー

1. 店舗詳細ページの「メニュー」タブを選択する（デフォルトで選択済み）
2. メニューがカード形式でリスト表示される
    - 各メニューカードには以下を表示する
        - メニュー名
        - 所要時間
        - 料金
        - メニューの簡単な説明（2行まで、超過分は省略）
3. メニューカードをクリックすると、メニュー詳細がモーダルで表示される
    - メニュー名
    - 詳細説明
    - 所要時間
    - 料金
    - 担当可能なスタッフ一覧（アバターとスタッフ名のリスト）
    - 「このメニューで予約する」ボタン
4. 「このメニューで予約する」ボタンをクリックすると、予約フローに遷移する（メニューが選択済みの状態で）

### 補足

- メニューが多い場合はカテゴリーごとにグルーピングして表示する
- モーダルはモバイルではフルスクリーンのドロワー（画面下部からスライドアップ）で表示する

---

## スタッフのプロフィールを閲覧する

### トリガー

- 店舗詳細ページの「スタッフ」タブを選択
- メニュー詳細モーダルの担当スタッフ一覧からスタッフ名をクリック

### フロー

1. 店舗詳細ページの「スタッフ」タブを選択する
2. スタッフがカード形式でリスト表示される
    - 各スタッフカードには以下を表示する
        - プロフィール画像（アバター）
        - スタッフ名
        - 自己紹介文（2行まで、超過分は省略）
3. スタッフカードをクリックすると、スタッフ詳細がモーダルで表示される
    - プロフィール画像
    - スタッフ名
    - 自己紹介文（全文）
    - 担当メニュー一覧
    - 「このスタッフで予約する」ボタン
4. 「このスタッフで予約する」ボタンをクリックすると、予約フローに遷移する（スタッフが選択済みの状態で）

### 補足

- モーダルはモバイルではフルスクリーンのドロワー（画面下部からスライドアップ）で表示する
