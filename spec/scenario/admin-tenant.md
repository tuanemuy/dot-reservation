# テナント管理者 - テナント管理

## テナント（店舗）を新規登録する

### トリガー

- ログイン後のテナント選択ページで「新しいテナントを登録」ボタンをクリック
- テナント未所属の場合、ログイン後に表示されるページの「テナントを新規登録する」ボタンをクリック

### フロー

1. テナント新規登録ページに遷移する（ステップ形式）
2. **ステップ1: 基本情報**
    - テナント名（店舗名）を入力する
    - カテゴリーをドロップダウンで選択する（整体院、ジム、美容院など）
    - URLパス（`/{url-path}` で使用される一意の文字列）を入力する
        - 入力中にリアルタイムで使用可否をチェックし、フィールド横にアイコンで結果を表示する
    - 「次へ」ボタンをクリックする
3. **ステップ2: 所在地・連絡先**
    - 郵便番号を入力する（入力すると住所を自動補完する）
    - 都道府県・市区町村・番地を入力する
    - 電話番号を入力する
    - 「次へ」ボタンをクリックする
4. **ステップ3: 確認**
    - 入力内容を確認する
    - 「登録する」ボタンをクリックする
5. 登録完了メッセージを表示し、テナントダッシュボードに遷移する
    - 初期セットアップのガイド（営業設定、メニュー登録、スタッフ登録を促すチェックリスト）がダッシュボード上部に表示される

### 補足

- テナント登録者は自動的にそのテナントの管理者ロールが付与される
- ステップインジケーターをページ上部に表示する

## テナントのプロフィールを編集する

### トリガー

- 管理画面サイドバーの「設定」>「テナント情報」をクリック

### フロー

1. テナント情報設定ページに遷移する
2. 現在の情報がフォームにプリフィルされた状態で表示される
    - テナント名（店舗名）
    - カテゴリー
    - URLパス
    - 郵便番号・住所
    - 電話番号
    - 店舗紹介文（リッチテキストエディター）
    - 店舗画像（複数アップロード可能、ドラッグ&ドロップ対応）
3. 必要な項目を編集する
    - URLパスを変更する場合はリアルタイムで使用可否をチェックする
    - 画像はサムネイルプレビューで表示し、並び替え（ドラッグ&ドロップ）や削除ができる
4. 「保存」ボタンをクリックする
5. 保存成功時、トースト通知で「テナント情報を更新しました」と表示する

### 補足

- URLパスを変更した場合、旧URLは無効になる旨の警告を変更前にインラインで表示する
- 画像は最大10枚までアップロード可能とする

## テナントを削除する

### トリガー

- テナント情報設定ページ最下部の「テナントを削除」ボタンをクリック

### フロー

1. テナント情報設定ページ最下部の「テナントを削除」ボタン（赤色テキスト）をクリックする
2. 確認モーダルが表示される
    - 「テナントを削除すると、すべてのデータ（メニュー、スタッフ、予約等）が削除され、元に戻すことはできません。」というメッセージ
    - 未来の予約がある場合、「未来の予約が○件あります。」と警告を表示する
    - 確認のためテナント名を入力するテキストフィールドを表示する
3. テナント名を正確に入力し、「削除する」ボタン（赤色）をクリックする
4. テナントが削除され、テナント選択ページにリダイレクトする
5. 「テナントを削除しました」というメッセージをトースト通知で表示する

### 補足

- 未来の予約がある場合でも削除は可能とするが、予約者への通知が送信される
- 削除後、テナントのURLパスは他のテナントが使用できるようになる
- テナントのすべてのメンバーに削除通知が送信される
