# テナント管理者 - 予約設定

## 予約設定を閲覧する

### トリガー

- 管理画面サイドバーの「設定」>「予約設定」をクリック

### フロー

1. 予約設定ページに遷移する
2. 現在の設定が一覧形式で表示される
    - **予約受付期間**: ○日後まで
    - **予約受付締切**: ○時間前まで
    - **キャンセル期限**: ○時間前まで
    - **予約枠の時間単位**: ○分
    - **予約間のバッファ時間**: ○分
    - **予約の承認方法**: 自動承認 / 手動承認
3. 各項目の横に簡単な説明テキストを表示する

---

## 予約設定を変更する

### トリガー

- 予約設定ページの「編集」ボタンをクリック

### フロー

1. 予約設定ページの「編集」ボタンをクリックする
2. ページがインラインで編集モードに切り替わる
3. 各項目を設定する

    - **予約受付期間**
        - 「何日後まで予約を受け付けるか」をドロップダウンで選択する（7日 / 14日 / 30日 / 60日 / 90日）

    - **予約受付締切**
        - 「何時間前まで予約を受け付けるか」をドロップダウンで選択する（1時間前 / 2時間前 / 3時間前 / 6時間前 / 12時間前 / 24時間前）

    - **キャンセル期限**
        - 「何時間前までキャンセルを受け付けるか」をドロップダウンで選択する（1時間前 / 2時間前 / 3時間前 / 6時間前 / 12時間前 / 24時間前 / 48時間前）

    - **予約枠の時間単位**
        - 予約の時間枠の単位をドロップダウンで選択する（15分 / 30分 / 60分）
        - 説明テキスト:「顧客が予約可能な時間枠の間隔です（例: 30分の場合、10:00、10:30、11:00...）」

    - **予約間のバッファ時間**
        - 予約と予約の間に確保する空き時間をドロップダウンで選択する（なし / 5分 / 10分 / 15分 / 30分）
        - 説明テキスト:「準備や片付けのために、予約の間に空ける時間です」

    - **予約の承認方法**
        - ラジオボタンで選択する
            - **自動承認**: 顧客が予約すると即座に確定される
            - **手動承認**: 管理者が予約を確認してから承認する
        - 各選択肢の下に説明テキストを表示する

4. 「保存」ボタンをクリックする
5. トースト通知で「予約設定を更新しました」と表示する
6. 表示モードに戻る

### 補足

- 設定変更は新しい予約から適用される（既存の予約には影響しない）
- 承認方法を「手動承認」から「自動承認」に変更した場合、「承認待ち」の予約がある場合は注意書きを表示する（「現在○件の承認待ち予約があります。これらの予約は自動承認されません。」）
