# 顧客 - 通知

## 通知の一覧を閲覧する

### トリガー

- ヘッダーのベルアイコンをクリック

### フロー

1. ヘッダー右上のベルアイコンをクリックする
    - 未読通知がある場合、ベルアイコンにバッジ（未読件数）を表示する
2. 通知パネルがドロップダウンとして表示される
    - 最新の通知が上から順に一覧表示される
    - 各通知には以下の情報を表示する
        - 通知タイプのアイコン（予約確定、予約変更、予約キャンセル、リマインダーなど）
        - 通知メッセージの概要（1行）
        - 受信日時（「3分前」「昨日」などの相対表示）
    - 未読の通知は背景色で区別する
3. 通知をクリックすると、関連するページ（予約詳細など）に遷移する
    - 遷移と同時に、クリックした通知は既読になる
4. ドロップダウン下部の「すべての通知を見る」リンクをクリックすると、通知一覧ページに遷移する

### 通知一覧ページ

1. 通知一覧ページでは、すべての通知を時系列で表示する
2. ページ上部に「すべて既読にする」ボタンを配置する
3. 通知の種類でフィルタリングできるタブを配置する
    - すべて / 予約関連 / お知らせ
4. ページネーションで過去の通知を閲覧できる

### 補足

- 通知の種類
    - 予約確定通知
    - 予約変更通知（店舗側からの変更）
    - 予約キャンセル通知（店舗側からのキャンセル）
    - 予約リマインダー（予約日前日）
    - 予約承認待ち通知（手動承認の場合）
    - 予約承認/却下通知

## 通知設定を変更する

### トリガー

- 通知一覧ページの「通知設定」ボタンをクリック
- マイページのサイドメニューから「通知設定」をクリック

### フロー

1. 通知設定ページに遷移する
2. 通知チャネルごとに設定を表示する
    - メール通知
        - 各通知種別のON/OFFトグルスイッチ
            - 予約確定
            - 予約変更
            - 予約キャンセル
            - 予約リマインダー
            - 予約承認結果
    - アプリ内通知
        - 各通知種別のON/OFFトグルスイッチ（メール通知と同じ項目）
3. トグルスイッチを切り替えると、即座に設定が保存される（自動保存）
4. 保存完了時、トグル横に一瞬チェックマークを表示してフィードバックする

### 補足

- アプリ内通知は常にONのままにし、OFFにできないものもある（予約確定通知など重要な通知）
- メール通知はすべてOFFにできる
