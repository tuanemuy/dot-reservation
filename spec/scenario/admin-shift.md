# テナント管理者 - シフト管理

## スタッフのシフトを登録する

### トリガー

- シフト管理ページの「シフトを追加」ボタンをクリック
- シフトカレンダーの日付セルをクリック

### フロー

1. 管理画面サイドバーの「シフト管理」をクリックし、シフト管理ページに遷移する
2. シフトカレンダーが表示される（週表示/月表示をタブで切り替え可能）
    - 縦軸: スタッフ名
    - 横軸: 日付
    - 各セルにシフトの有無と時間帯を表示
3. 「シフトを追加」ボタンをクリック、またはカレンダーの空セルをクリックする
4. シフト登録モーダルが表示される
    - スタッフをドロップダウンで選択する（セルクリックの場合はプリセット）
    - 日付をカレンダーピッカーで選択する（セルクリックの場合はプリセット）
    - 開始時刻と終了時刻をドロップダウン（時間選択）で設定する
    - 繰り返し設定（任意）
        - なし（デフォルト）
        - 毎週（終了日を指定）
    - 「登録する」ボタンをクリックする
5. トースト通知で「シフトを登録しました」と表示する
6. カレンダーにシフトが反映される

### 補足

- 営業時間外のシフトは登録できない（バリデーションエラー）
- 既にシフトが登録されている時間帯と重複する場合、エラーメッセージを表示する
- スタッフからのシフト希望が提出されている場合、カレンダー上にシフト希望を薄い色で表示する

## スタッフのシフトを編集する

### トリガー

- シフトカレンダー上の既存シフトをクリック

### フロー

1. カレンダー上の既存シフト（色付きブロック）をクリックする
2. シフト詳細ポップオーバーが表示される
    - スタッフ名
    - 日付
    - 時間帯
    - 「編集」ボタンと「削除」ボタン
3. 「編集」ボタンをクリックする
4. シフト編集モーダルが表示される
    - 現在の情報がプリフィルされた状態で表示される
    - 開始時刻と終了時刻を変更できる
    - 繰り返しシフトの場合、「この日のみ変更」「以降すべて変更」を選択できるラジオボタンを表示する
    - 「保存」ボタンをクリックする
5. トースト通知で「シフトを更新しました」と表示する
6. カレンダーが更新される

### 補足

- シフト時間内に予約が入っている場合、予約に影響する変更（時間短縮など）を行おうとすると警告を表示する

## スタッフのシフトを削除する

### トリガー

- シフト詳細ポップオーバーの「削除」ボタンをクリック

### フロー

1. カレンダー上のシフトをクリックし、ポップオーバーを表示する
2. 「削除」ボタンをクリックする
3. 確認モーダルが表示される
    - 「このシフトを削除しますか？」というメッセージ
    - 繰り返しシフトの場合、「この日のみ削除」「以降すべて削除」を選択できるラジオボタンを表示する
    - シフト時間内に予約がある場合、「このシフト時間に○件の予約があります。」と警告を表示する
    - 「削除する」ボタン（赤色）と「キャンセル」ボタン
4. 「削除する」ボタンをクリックする
5. トースト通知で「シフトを削除しました」と表示する
6. カレンダーからシフトが消える

### 補足

- シフトを削除しても既存の予約は自動キャンセルされない（手動対応が必要）

## スタッフのシフト一覧を閲覧する

### トリガー

- 管理画面サイドバーの「シフト管理」をクリック

### フロー

1. シフト管理ページに遷移する
2. シフトカレンダーが表示される
    - **週表示**（デフォルト）
        - 縦軸にスタッフ名、横軸に曜日（月〜日）
        - 各セルにシフトの時間帯を色付きブロックで表示
        - 前の週/次の週ナビゲーションボタン
    - **月表示**
        - 月間カレンダー形式
        - 各日付セルにシフトのあるスタッフ名を表示（省略表示、クリックで展開）
        - 前の月/次の月ナビゲーションボタン
3. スタッフでフィルタリングできるドロップダウンをカレンダー上部に配置する
    - 「すべてのスタッフ」/ 個別スタッフ名
4. スタッフからのシフト希望がある場合、カレンダー上に薄い色の背景で表示する

### 補足

- カレンダーの表示切り替え（週/月）はタブで行う
- 当日の列/セルはハイライト表示する
- シフト未登録の日には空セルが表示され、クリックでシフト登録モーダルを開ける
