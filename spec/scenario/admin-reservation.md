# テナント管理者 - 予約管理

## 予約の一覧を閲覧する

### トリガー

- 管理画面サイドバーの「予約管理」をクリック

### フロー

1. 予約管理ページに遷移する
2. 表示形式を切り替えるタブを配置する
    - **リスト表示**（デフォルト）
    - **カレンダー表示**
3. **リスト表示**
    - 予約の一覧がテーブル形式で表示される
    - 各行には以下を表示する
        - 予約ステータスのバッジ（承認待ち、確定、完了、キャンセル済み）
        - 顧客名
        - メニュー名
        - 担当スタッフ名
        - 予約日時
        - アクションメニュー（三点リーダー）
    - テーブル上部にフィルター機能を配置する
        - ステータス（ドロップダウン: すべて / 承認待ち / 確定 / 完了 / キャンセル済み）
        - スタッフ（ドロップダウン）
        - 日付範囲（カレンダーピッカーで開始日・終了日を選択）
    - デフォルトでは「今日以降の予約」を「予約日時が近い順」に表示する
    - ページネーション対応
4. **カレンダー表示**
    - 週表示のカレンダー
        - 縦軸: 時間帯
        - 横軸: 日付
        - 予約が色付きブロックで表示される（ステータスで色分け）
    - 前の週/次の週ナビゲーションボタン
    - スタッフでフィルタリングできるドロップダウンをカレンダー上部に配置する
    - 予約ブロックをクリックすると予約詳細ポップオーバーが表示される

### 補足

- 承認待ちの予約がある場合、ページ上部に「○件の承認待ち予約があります」とバナーを表示する
- カレンダー表示では、各スタッフの予約を色で区別できるようにする

## 予約の詳細を閲覧する

### トリガー

- 予約一覧（リスト表示）の予約行をクリック
- カレンダー表示の予約ブロックのポップオーバーから「詳細を見る」をクリック

### フロー

1. 予約詳細ページに遷移する
2. 以下の情報を表示する
    - 予約ステータス（承認待ち、確定、完了、キャンセル済み）
    - 顧客情報
        - 顧客名
        - メールアドレス
        - 電話番号
    - 予約内容
        - メニュー名
        - 所要時間
        - 料金
        - 担当スタッフ名
        - 予約日時
        - 備考
    - 予約登録日時
3. ステータスに応じたアクションボタンを表示する
    - 承認待ち:「承認する」「却下する」ボタン
    - 確定:「変更する」「キャンセルする」ボタン
    - 完了: アクションボタンなし
    - キャンセル済み: アクションボタンなし

## 予約を代理で登録する

### トリガー

- 予約管理ページの「予約を登録」ボタンをクリック
- カレンダー表示の空き時間帯をクリック

### フロー

1. 「予約を登録」ボタンをクリックする
2. 代理予約登録ページに遷移する
3. 以下の情報を入力する
    - **顧客情報**
        - 既存顧客を検索（名前・メールアドレスで検索、ドロップダウンで候補表示）
        - または新規顧客情報を入力（名前、メールアドレス、電話番号）
    - **メニュー選択**
        - メニューをドロップダウンで選択する
    - **スタッフ選択**
        - スタッフをドロップダウンで選択する（選択したメニューの担当スタッフのみ表示）
    - **日時選択**
        - 日付をカレンダーピッカーで選択する
        - 空き時間枠から時間を選択する
    - **備考**（テキストエリア、任意）
4. 「登録する」ボタンをクリックする
5. 代理登録の場合は自動的に「確定」ステータスで登録される
6. トースト通知で「予約を登録しました」と表示する
7. 予約詳細ページにリダイレクトする

### 補足

- 顧客にメールアドレスが入力されている場合、予約確認メールが送信される
- 電話予約などを受けた際に使用する機能

## 予約を承認する

### トリガー

- 予約詳細ページの「承認する」ボタンをクリック
- 予約一覧のアクションメニューから「承認する」を選択

### フロー

1. 「承認する」ボタンをクリックする
2. 確認モーダルが表示される
    - 予約内容のサマリー
    - 「承認する」ボタンと「キャンセル」ボタン
3. 「承認する」ボタンをクリックする
4. 予約ステータスが「確定」に変更される
5. トースト通知で「予約を承認しました」と表示する
6. 顧客に予約確定通知が送信される

### 却下する場合

1. 予約詳細ページの「却下する」ボタンをクリックする
2. 却下モーダルが表示される
    - 却下理由を入力するテキストエリア（任意）
    - 「却下する」ボタン（赤色）と「キャンセル」ボタン
3. 「却下する」ボタンをクリックする
4. 予約ステータスが「却下」に変更される（顧客による「キャンセル済み」とは区別される）
5. トースト通知で「予約を却下しました」と表示する
6. 顧客に却下通知が送信される（却下理由を含む）

---

## 予約を変更する

### トリガー

- 予約詳細ページの「変更する」ボタンをクリック

### フロー

1. 予約詳細ページの「変更する」ボタンをクリックする
2. 予約変更ページに遷移する
    - 現在の予約内容がプリフィルされた状態で表示される
    - メニュー、スタッフ、日時を変更できる
3. 変更内容を確認する画面で、変更前と変更後の差分をハイライトして表示する
4. 「変更を確定する」ボタンをクリックする
5. トースト通知で「予約を変更しました」と表示する
6. 予約詳細ページにリダイレクトする
7. 顧客に予約変更通知が送信される

---

## 予約をキャンセルする

### トリガー

- 予約詳細ページの「キャンセルする」ボタンをクリック

### フロー

1. 予約詳細ページの「キャンセルする」ボタンをクリックする
2. 確認モーダルが表示される
    - 「この予約をキャンセルしますか？」というメッセージ
    - 予約内容のサマリー
    - キャンセル理由を入力するテキストエリア（任意）
    - 「キャンセルする」ボタン（赤色）と「戻る」ボタン
3. 「キャンセルする」ボタンをクリックする
4. 予約ステータスが「キャンセル済み」に変更される
5. トースト通知で「予約をキャンセルしました」と表示する
6. 顧客にキャンセル通知が送信される（キャンセル理由を含む）

### 補足

- 店舗側からのキャンセルはキャンセル期限に関係なくいつでも可能
