# DB設計レビュー #001

## レビュー結果

問題なし。

- 全ドメインのエンティティに対応するテーブルが揃っている
- 正規化が適切（臨時休業日を別テーブルに分離、スタッフ担当メニューの中間テーブル）
- SQLite/Turso の制約に合った型設計（TEXT for ID, INTEGER for timestamp）
- 予約テーブルのスナップショットフィールドとFK制約なしの設計が適切（メニュー/スタッフ削除時のデータ保持）
- インデックスが主要なクエリパターン（テナントID+日付、ステータス絞り込み等）をカバー
- Outboxパターン用のテーブルが含まれている
- JSON列の使用が営業時間・画像URL等の柔軟なデータに限定されており適切
