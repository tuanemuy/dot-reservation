# listPendingInvitations — 受け取った招待一覧を取得する

## テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| メンバーのメールアドレス宛に承認待ちの招待が複数存在する | email を指定して listPendingInvitations を実行する | 未対応の招待一覧が返却される | 未実装 |
| メンバーのメールアドレス宛に期限切れの招待が存在する | listPendingInvitations を実行する | 期限切れの招待は含まれない | 未実装 |
| メンバーのメールアドレス宛に承認済みの招待が存在する | listPendingInvitations を実行する | 承認済みの招待は含まれない | 未実装 |
| メンバーのメールアドレス宛に辞退済みの招待が存在する | listPendingInvitations を実行する | 辞退済みの招待は含まれない | 未実装 |
| メンバーのメールアドレス宛に取り消し済みの招待が存在する | listPendingInvitations を実行する | 取り消し済みの招待は含まれない | 未実装 |
| メンバーのメールアドレス宛に招待が存在しない | listPendingInvitations を実行する | 空の items 配列が返却される | 未実装 |
| 異なるテナントからの承認待ち招待が複数存在する | listPendingInvitations を実行する | 全テナントからの未対応招待が返却される | 未実装 |
