# 認証統合テストケース

## cleanupAuthUserIfOrphaned

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| Customer も Member も存在しない | cleanupAuthUserIfOrphaned を実行する | auth ユーザーが削除される | |
| Customer のみ存在する | cleanupAuthUserIfOrphaned を実行する | auth ユーザーは維持される | |
| Member のみ存在する | cleanupAuthUserIfOrphaned を実行する | auth ユーザーは維持される | |
| Customer と Member の両方が存在する | cleanupAuthUserIfOrphaned を実行する | auth ユーザーは維持される | |

## deleteCustomer — auth 統合

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 顧客のみ持つユーザー | deleteCustomer を実行する | Customer 削除、auth ユーザーも削除される | |
| 顧客とメンバー両方持つユーザー | deleteCustomer を実行する | Customer 削除、auth ユーザーは維持される（Member が存在するため） | |
| 顧客アカウント削除後（メンバーあり） | メンバーとしてログインする | 正常にログインでき、管理画面にアクセスできる | |
| 顧客アカウント削除後（メンバーなし） | 同メールアドレスで新規登録する | 正常に新規登録できる | |

## suspendCustomer — auth 統合

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アクティブな顧客が存在する | suspendCustomer を実行する | Customer.status が "suspended" になる。auth ユーザーは BAN されない | |
| 停止された顧客（メンバーでもある） | メンバーとしてログインする | 正常にログインでき、管理画面にアクセスできる | |
| 停止された顧客 | 顧客ページにアクセスする | アカウント停止エラーページが表示される | |
| 停止された顧客 | ログインを試みる | ログイン自体は成功する（auth BAN ではないため） | |

## reactivateCustomer — auth 統合

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 停止中の顧客が存在する | reactivateCustomer を実行する | Customer.status が "active" になる | |
| 再開された顧客 | 顧客ページにアクセスする | 正常にアクセスできる | |

## deleteMemberAccount — auth 統合

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| メンバーのみ持つユーザー | deleteMemberAccount を実行する | 全テナントから脱退、auth ユーザーも削除される | |
| メンバーと顧客両方持つユーザー | deleteMemberAccount を実行する | 全テナントから脱退、auth ユーザーは維持される（Customer が存在するため） | |
| メンバーアカウント削除後（顧客あり） | 顧客としてログインする | 正常にログインでき、顧客ページにアクセスできる | |
| メンバーアカウント削除後（顧客なし） | 同メールアドレスで新規登録する | 正常に新規登録できる | |

## クロス登録フロー

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 顧客として登録済み | メンバー新規登録ページで同メールで登録を試みる | 「メールアドレスは既に登録されています。ログインしてください。」と表示される | |
| 顧客として登録済み | 管理画面ログインページでログインする | セッション作成成功、/admin/setup にリダイレクトされる | |
| 顧客として登録済み、管理画面でログイン後 | /admin/setup でメンバープロフィールを作成する | Member エンティティが作成され、テナント選択ページにリダイレクトされる | |
| メンバーとして登録済み | 顧客新規登録ページで同メールで登録を試みる | 「メールアドレスは既に登録されています。ログインしてください。」と表示される | |
| メンバーとして登録済み | 顧客ログインページでログインする | セッション作成成功、/customer/setup にリダイレクトされる | |
| メンバーとして登録済み、顧客ページでログイン後 | /customer/setup で顧客プロフィールを作成する | Customer エンティティが作成され、マイページにリダイレクトされる | |

## メールアドレス変更 — auth 統合

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 顧客のみ持つユーザー | メールアドレスを変更し確認する | auth ユーザーと Customer の email が更新される | |
| 顧客とメンバー両方持つユーザー | メールアドレスを変更し確認する | auth ユーザーと Customer と全 Member の email が更新される | |
| メール変更先が既に使用されている | authClient.changeEmail を呼び出す | エラーが返される | |

## ルートローダーのセッション検証

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 未認証状態 | 顧客マイページにアクセスする | /customer/login にリダイレクトされる | |
| 未認証状態 | 管理画面にアクセスする | /admin/login にリダイレクトされる | |
| 未認証状態 | プラットフォーム管理画面にアクセスする | /platform/login にリダイレクトされる | |
| ログイン済みだが Customer 未作成 | 顧客マイページにアクセスする | /customer/setup にリダイレクトされる | |
| ログイン済みだが Member 未作成 | 管理画面にアクセスする | /admin/setup にリダイレクトされる | |
| role="user" のユーザーでログイン済み | プラットフォーム管理画面にアクセスする | /platform/login にリダイレクトされる | |
| role="admin" のユーザーでログイン済み | プラットフォーム管理画面にアクセスする | 管理ダッシュボードが表示される | |
| 顧客が停止中（status="suspended"） | 顧客マイページにアクセスする | アカウント停止エラーページが表示される | |

## プラットフォームレベル BAN

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 顧客とメンバー両方持つユーザー | authProvider.banUser で BAN する | 全セッション無効化、顧客ページにもメンバーページにもアクセス不可 | |
| BAN されたユーザー | ログインを試みる | ログインが拒否される | |
| BAN されたユーザー | authProvider.unbanUser で BAN 解除する | ログインが可能になり、顧客・メンバー両方にアクセスできる | |
