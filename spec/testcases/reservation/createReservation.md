# createReservation — 予約を作成する テストケース

## 正常系

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| テナントの承認方法が「自動承認」に設定されている | 有効な入力DTOで予約を作成する | ステータスが「confirmed」の予約が作成され、予約IDが返される | 未実装 |
| テナントの承認方法が「手動承認」に設定されている | 有効な入力DTOで予約を作成する | ステータスが「pending」の予約が作成され、予約IDが返される | 未実装 |
| staffProfileIdがnullで、対象時間枠に空きスタッフが複数存在する | 「指名なし」で予約を作成する | 空きスタッフの中から1名が自動的に割り当てられ、予約が作成される | 未実装 |
| staffProfileIdがnullで、対象時間枠に空きスタッフが1名のみ存在する | 「指名なし」で予約を作成する | その唯一の空きスタッフが割り当てられ、予約が作成される | 未実装 |
| 有効なメニューが存在する | 予約を作成する | メニュー名、所要時間、料金がスナップショットとして予約に保存される | 未実装 |
| 顧客のメールアドレスが登録されている | 予約を作成する | 予約作成後に確認メールが送信される | 未実装 |
| noteにテキストを指定する | 予約を作成する | 備考が保存された状態で予約が作成される | 未実装 |
| noteがnullである | 予約を作成する | 備考なしで予約が作成される | 未実装 |

## 異常系

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 指定した時間枠に既に予約が入っている | 予約を作成する | ConflictErrorが発生する | 未実装 |
| 指定したスタッフの当該時間枠に既に予約が入っている | スタッフを指名して予約を作成する | ConflictErrorが発生する | 未実装 |
| 予約受付締切時刻を過ぎている | 予約を作成する | バリデーションエラーが発生する | 未実装 |
| 予約受付開始日より前の日付を指定する | 予約を作成する | バリデーションエラーが発生する | 未実装 |
| 予約受付終了日より後の日付を指定する | 予約を作成する | バリデーションエラーが発生する | 未実装 |
| テナントが停止中である | 予約を作成する | ForbiddenErrorが発生する | 未実装 |
| staffProfileIdがnullで、対象時間枠に空きスタッフが存在しない | 「指名なし」で予約を作成する | ConflictErrorが発生する | 未実装 |
| 存在しないtenantIdを指定する | 予約を作成する | NotFoundErrorが発生する | 未実装 |
| 存在しないmenuIdを指定する | 予約を作成する | NotFoundErrorが発生する | 未実装 |
| 存在しないcustomerIdを指定する | 予約を作成する | NotFoundErrorが発生する | 未実装 |
| 存在しないstaffProfileIdを指定する | 予約を作成する | NotFoundErrorが発生する | 未実装 |
| 指定したスタッフが該当メニューを担当していない | 予約を作成する | バリデーションエラーが発生する | 未実装 |
| 指定した日時がスタッフのシフト外である | 予約を作成する | ConflictErrorが発生する | 未実装 |

## 境界値・エッジケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 予約受付締切のちょうど直前の時刻である | 予約を作成する | 正常に予約が作成される | 未実装 |
| 予約受付締切のちょうどの時刻である | 予約を作成する | バリデーションエラーが発生する | 未実装 |
| 予約受付期間の初日を指定する | 予約を作成する | 正常に予約が作成される | 未実装 |
| 予約受付期間の最終日を指定する | 予約を作成する | 正常に予約が作成される | 未実装 |
| 営業開始時刻ちょうどに予約する | 予約を作成する | 正常に予約が作成される | 未実装 |
| 営業終了時刻にメニューの所要時間が収まるギリギリの時刻に予約する | 予約を作成する | 正常に予約が作成される | 未実装 |
| 営業終了時刻にメニューの所要時間が収まらない時刻に予約する | 予約を作成する | ConflictErrorが発生する | 未実装 |
| 同一スタッフに連続する時間枠で予約が入っており、バッファ時間と重なる | 予約を作成する | ConflictErrorが発生する | 未実装 |
