# updateRegularHolidays — 定休日を更新する テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アクティブなテナントが存在する | 有効な曜日値（例: [0, 6]）でupdateRegularHolidaysを実行する | 定休日が正常に更新される | 未実装 |
| アクティブなテナントが存在する | 空配列でupdateRegularHolidaysを実行する（定休日なし） | 定休日がなしに更新される | 未実装 |
| アクティブなテナントが存在する | 全曜日（[0,1,2,3,4,5,6]）を定休日に設定する | 正常に更新される | 未実装 |
| アクティブなテナントが存在する | 無効な曜日値（例: 7）を含む配列を指定する | ValidationErrorがスローされる | 未実装 |
| アクティブなテナントが存在する | 負の曜日値（例: -1）を含む配列を指定する | ValidationErrorがスローされる | 未実装 |
| アクティブなテナントが存在する | 重複する曜日値（例: [0, 0, 1]）を含む配列を指定する | ValidationErrorがスローされる、または重複が自動的に除去される | 未実装 |
| 存在しないtenantIdを指定する | updateRegularHolidaysを実行する | NotFoundErrorがスローされる | 未実装 |
