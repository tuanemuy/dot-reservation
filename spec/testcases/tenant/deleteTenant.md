# deleteTenant — テナントを削除する テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アクティブなテナントが存在し、予約がない | deleteTenantを実行する | テナントが正常に削除される | 未実装 |
| 削除されたテナントのtenantIdを指定する | getTenantを実行する | NotFoundErrorがスローされる（削除が永続化されている） | 未実装 |
| テナントに未来の確定予約がある | deleteTenantを実行する | テナントが削除され、予約者に通知が送信される | 未実装 |
| テナントに過去の予約のみある | deleteTenantを実行する | テナントが正常に削除される | 未実装 |
| 存在しないtenantIdを指定する | deleteTenantを実行する | NotFoundErrorがスローされる | 未実装 |
| テナントにメンバーが複数存在する | deleteTenantを実行する | テナントと関連する全メンバーデータが削除される | 未実装 |
| テナントに営業設定・予約設定が存在する | deleteTenantを実行する | テナントと関連する全設定データが削除される | 未実装 |
| テナントに臨時休業日が登録されている | deleteTenantを実行する | テナントと関連する全臨時休業日データが削除される | 未実装 |
| 停止中のテナントが存在する | deleteTenantを実行する | テナントが正常に削除される | 未実装 |
