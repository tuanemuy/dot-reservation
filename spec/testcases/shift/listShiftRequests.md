# listShiftRequests - シフト希望を取得する テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| テナントに複数スタッフのシフト希望が期間内に提出されている | tenantId, startDate, endDate を指定してシフト希望一覧を取得する | 期間内のすべてのシフト希望が items に返される | 未実装 |
| テナントに複数スタッフのシフト希望が提出されている | staffProfileId を指定してフィルタリングする | 指定スタッフのシフト希望のみが返される | 未実装 |
| テナントにシフト希望が提出されているが、指定期間外のみ | tenantId, startDate, endDate を指定してシフト希望一覧を取得する | items に空配列が返される | 未実装 |
| テナントにシフト希望が1件も提出されていない | tenantId, startDate, endDate を指定してシフト希望一覧を取得する | items に空配列が返される | 未実装 |
| テナントにシフト希望が提出されている | staffProfileId に null を指定してシフト希望一覧を取得する | 全スタッフのシフト希望が返される（フィルタなし） | 未実装 |
| 指定期間の境界にシフト希望がある（startDate 当日、endDate 当日） | 境界日のシフト希望を含む期間を指定して取得する | 境界日のシフト希望が含まれる | 未実装 |
| 複数テナントにシフト希望が提出されている | テナントAの tenantId を指定してシフト希望一覧を取得する | テナントAのシフト希望のみが返され、他のテナントの希望は含まれない | 未実装 |
| 勤務希望と休み希望が混在している | tenantId, startDate, endDate を指定してシフト希望一覧を取得する | 勤務希望（type="work"）と休み希望（type="off"）の両方が含まれる | 未実装 |
| テナントにシフト希望が複数提出されている | シフト希望一覧を取得する | 各希望が ShiftRequestDetail 形式で正しく返される | 未実装 |
