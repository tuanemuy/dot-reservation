# updateShift - シフトを編集する テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 単発シフトが存在する | 有効な startTime, endTime, updateScope="single" を指定して編集する | シフトの時間帯が正常に更新される | 未実装 |
| 繰り返しシフトが存在する（複数週分） | updateScope="single" を指定して特定日のシフトを編集する | 指定した日のシフトのみが更新され、他の週のシフトは変更されない | 未実装 |
| 繰り返しシフトが存在する（複数週分） | updateScope="future" を指定してシフトを編集する | 指定した日以降のすべてのシフトが更新される | 未実装 |
| 繰り返しシフトが存在する（複数週分） | updateScope="future" を指定して最初の週のシフトを編集する | すべての週のシフトが更新される | 未実装 |
| 繰り返しシフトが存在する（複数週分） | updateScope="future" を指定して最後の週のシフトを編集する | 最後の週のシフトのみが更新される | 未実装 |
| シフトが存在し、同日同スタッフに別のシフトがある | 既存の別シフトと重複する時間帯に編集する | ConflictError がスローされる | 未実装 |
| シフトが存在し、同日同スタッフに別のシフトがある | 既存の別シフトと重複しない時間帯に編集する | 正常に更新される | 未実装 |
| シフト内に予約が入っている | シフトの時間帯を短縮するように編集する（予約が範囲外になる） | 警告情報が返される | 未実装 |
| シフト内に予約が入っている | シフトの時間帯を拡大するように編集する（予約は範囲内のまま） | 正常に更新され、警告は返されない | 未実装 |
| シフト内に予約が入っていない | シフトの時間帯を短縮するように編集する | 正常に更新され、警告は返されない | 未実装 |
| 存在しないシフトID | 存在しない shiftId を指定して編集する | NotFoundError がスローされる | 未実装 |
| シフトが存在する | 開始時刻が終了時刻より後の値で編集する | バリデーションエラーがスローされる（TimeRange: start < end） | 未実装 |
| シフトが存在する | 開始時刻と終了時刻が同じ値で編集する | バリデーションエラーがスローされる（TimeRange: start < end） | 未実装 |
| シフトが存在する | 15分単位でない時刻を指定して編集する | バリデーションエラーがスローされる（TimeOfDay は15分単位） | 未実装 |
| シフトが存在する | 営業時間外の時間帯に編集する | バリデーションエラーがスローされる | 未実装 |
| 繰り返しシフトの「以降すべて」を編集する際、一部の週に重複がある | updateScope="future" で編集する | ConflictError がスローされ、いずれのシフトも更新されない（トランザクション整合性） | 未実装 |
