# listShifts - シフト一覧を取得する テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| テナントに複数スタッフのシフトが期間内に登録されている | tenantId, startDate, endDate を指定してシフト一覧を取得する | 期間内のすべてのシフトが items に返される | 未実装 |
| テナントに複数スタッフのシフトが登録されている | staffProfileId を指定してフィルタリングする | 指定スタッフのシフトのみが返される | 未実装 |
| テナントにシフトが登録されているが、指定期間外のみ | tenantId, startDate, endDate を指定してシフト一覧を取得する | items に空配列が返される | 未実装 |
| テナントにシフトが1件も登録されていない | tenantId, startDate, endDate を指定してシフト一覧を取得する | items に空配列が返される | 未実装 |
| テナントにシフトが登録されている | staffProfileId に null を指定してシフト一覧を取得する | 全スタッフのシフトが返される（フィルタなし） | 未実装 |
| 指定期間の境界にシフトがある（startDate 当日、endDate 当日） | 境界日のシフトを含む期間を指定してシフト一覧を取得する | 境界日のシフトが含まれる | 未実装 |
| 複数テナントにシフトが登録されている | テナントAの tenantId を指定してシフト一覧を取得する | テナントAのシフトのみが返され、他のテナントのシフトは含まれない | 未実装 |
| テナントにシフトが複数登録されている | シフト一覧を取得する | 各シフトが ShiftDetail 形式で正しく返される | 未実装 |
| 繰り返しシフトと単発シフトが混在している | tenantId, startDate, endDate を指定してシフト一覧を取得する | 繰り返しシフトも単発シフトも区別なく一覧に含まれる | 未実装 |
