# updateStaffProfile - スタッフプロフィールを更新する テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| スタッフプロフィールが存在する | 有効な displayName, imageUrl, bio を指定して更新する | プロフィールが正常に更新され、更新後の id と displayName が返される | 未実装 |
| スタッフプロフィールが存在する | displayName のみを変更し、imageUrl と bio を null にして更新する | プロフィールが更新され、imageUrl と bio が null になる | 未実装 |
| スタッフプロフィールが存在する | imageUrl を新しい URL に変更して更新する | imageUrl が新しい値に更新される | 未実装 |
| スタッフプロフィールが存在する | bio を新しい文に変更して更新する | bio が新しい値に更新される | 未実装 |
| スタッフプロフィールが存在する | updatedAt が更新前と異なることを確認する | updatedAt が現在時刻に更新される | 未実装 |
| 指定した staffProfileId のプロフィールが存在しない | 存在しない staffProfileId を指定して更新する | NotFoundError がスローされる | 未実装 |
| スタッフプロフィールが存在する | displayName に空文字を指定して更新する | バリデーションエラーがスローされる（StaffDisplayName は1〜50文字） | 未実装 |
| スタッフプロフィールが存在する | displayName に51文字以上の文字列を指定して更新する | バリデーションエラーがスローされる（StaffDisplayName は1〜50文字） | 未実装 |
| スタッフプロフィールが存在する | displayName にちょうど50文字の文字列を指定して更新する | 正常に更新される（境界値テスト） | 未実装 |
| スタッフプロフィールが存在する | displayName にちょうど1文字の文字列を指定して更新する | 正常に更新される（境界値テスト） | 未実装 |
| スタッフプロフィールが存在する | bio に1001文字以上の文字列を指定して更新する | バリデーションエラーがスローされる（StaffBio は最大1000文字） | 未実装 |
| スタッフプロフィールが存在する | bio にちょうど1000文字の文字列を指定して更新する | 正常に更新される（境界値テスト） | 未実装 |
