# listStaffsByMenu - メニュー別スタッフ一覧を取得する テストケース

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| テナントにスタッフが複数おり、指定メニューを担当できるスタッフが複数いる | tenantId と menuId を指定してスタッフ一覧を取得する | 指定メニューを担当するスタッフのみが items に返される | 未実装 |
| テナントにスタッフが複数いるが、指定メニューを担当できるスタッフがいない | tenantId と menuId を指定してスタッフ一覧を取得する | items に空配列が返される | 未実装 |
| テナントにスタッフが1名おり、そのスタッフが指定メニューを担当している | tenantId と menuId を指定してスタッフ一覧を取得する | items に1件のスタッフプロフィールが返される | 未実装 |
| テナントにスタッフが複数おり、一部のスタッフのみが指定メニューを担当している | tenantId と menuId を指定してスタッフ一覧を取得する | 担当しているスタッフのみが返され、担当していないスタッフは含まれない | 未実装 |
| 複数のテナントにスタッフがいる | テナントAの tenantId と menuId を指定してスタッフ一覧を取得する | テナントAの該当スタッフのみが返され、他のテナントのスタッフは含まれない | 未実装 |
| テナントにスタッフはいるが、担当メニューが空配列（0件）のスタッフのみ | tenantId と menuId を指定してスタッフ一覧を取得する | items に空配列が返される | 未実装 |
